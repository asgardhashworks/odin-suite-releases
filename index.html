// 01 Modules

Three units. One operation.

Each part does one job and reports to the others. Install all three with a single wizard.

ODIN · TRADING

Hashrate order engine

Reads the live NiceHash order book every 2 seconds and buys SHA256 hashrate only while the margin is positive.

  • Learns how stable each price level is
  • Parks your order instead of chasing the price
  • Daily spend and loss kill switches
  • Verified P/L with Kryptex pools
SLEIPNIR · SUPERVISION

Miner supervisor

Starts your miners at boot, restarts any that crash, freeze or slow down, and alerts you before hardware cooks.

  • Core, hotspot, VRAM and ASIC chip temps
  • Polls hundreds of units in parallel
  • Power budget gauge in watts
  • Push alerts through ntfy
HUGINN · RECON

Phone dashboard

Trading and farm status on your phone over a private Tailscale link. Read-only by design.

  • Order book, decisions and orders
  • Farm as a console or as cards
  • Protected by a random key
  • Can't place, change or cancel anything

FREKI, optional: build notes for a CPU miner with 0% developer fee.

// 02 How ODIN decides

Bid only when it pays.

01

Read the book

Rates every price level on speed, miners, volume, fill and stability.

02

Price the hash

Works out what 1 EH/s earns now from live difficulty and block rewards, minus pool and NiceHash fees.

03

Lock or park

Locks a level once it holds steady. Above break-even, parks the order at your maximum and waits for a dip.

04

Protect capital

Hard price ceiling, step-limited raises, chase detection and daily kill switches run the whole time.

// 05 Security

Your keys never leave your PC.

Local secrets

API keys live in one settings file that only your Windows account can read. ODIN talks to NiceHash directly.

No withdrawals

Use a NiceHash key with withdrawals turned off. ODIN never needs to move coins out of your account.

Watch-only first

Every install starts in watch-only mode. Nothing trades until you switch it on yourself.

Verified builds

Programs are built by GitHub Actions. Each release ships SHA256 checksums to compare before you install.
