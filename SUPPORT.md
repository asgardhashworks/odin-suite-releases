## Before you contact support

1. Run `odin --version` and note the version.
2. Run `odin --verify-audit` and note the result.
3. Collect the last 50 lines of `odin_events.log` (Windows) or `journalctl -u odin -n 50` (Linux).
4. Remove API keys, wallet addresses and licence contents from anything you send.
